# Problema generale

Stai sviluppando il programma di un distributore automatico di alimenti e bevande.

Il distributore permette all'utente di scegliere una categoria, selezionare un prodotto e pagare utilizzando monete in euro. Dopo ogni acquisto, l'utente può decidere se comprare un altro prodotto oppure terminare.

All'inizio verranno gestite soltanto la scelta della categoria e l'inserimento del prezzo. Negli esercizi successivi saranno aggiunti il pagamento, il resto, gli acquisti consecutivi, le liste dei prodotti e le quantità disponibili.
